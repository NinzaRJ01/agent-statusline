What it shows

    
Two rows: the model, then your workspace.

    
Wide windows get one line. When that doesn't fit, it splits into an AI row and a workspace row, and narrow windows wrap each row on its own, up to three lines.

    

      
AI row
    
        
  • Model, reasoning effort and mode
    • 
        
  • Context window fill with a gauge: green, amber from 60%, red from 80%
    • 
        
  • Prompt cache hit rate for the current request
    • 
      

      
Workspace row
    
        
  • Git branch, dirty flag and uncommitted +/- lines, or the folder outside a repo
    • 
        
  • Usage limits left for the 5-hour and 7-day windows
    • 
        
  • Cost and duration, lines Claude edited, tool approvals, subagents and artifacts
    • 
      

    

  






  

    
Install

    
Clone, run the installer, done.

    
Needs Python 3.8+ and git. For the icon themes, use a terminal with truecolor and a Nerd Font. Ghostty ships the symbols built in; elsewhere install any Nerd Font or use the classic theme.

    
git clone https://github.com/NinzaRJ01/agent-statusline.git
cd agent-statusline
./install.sh

    

      
Links the commandagent-statusline goes into ~/.local/bin.

      
Configures both CLIsSets statusLine in the Claude Code and Antigravity settings, keeping everything else and saving a backup first.

      
Adds a slash command/statusline-theme switches themes from inside Claude Code.

    

  






  

    
Switch themes

    
One command, applied on the next refresh.

    
Set a theme for every tool or just one. The AGENT_STATUSLINE_THEME environment variable overrides both for a single shell.

    
# show the theme each tool uses
agent-statusline theme
# use capsule everywhere
agent-statusline theme capsule
# only Antigravity
agent-statusline theme minimal --tool agy
# print every theme with sample data in your terminal
agent-statusline preview

    
Run ./uninstall.sh to remove it. It only deletes statusline entries that point at agent-statusline and leaves your other settings alone.
